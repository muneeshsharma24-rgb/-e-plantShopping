
# e-plantShopping – Paradise Nursery

## Project Overview

e-plantShopping is an online plant shopping application developed for Paradise Nursery. It allows customers to explore different plants, view product information, add products to their shopping cart, update quantities, and calculate the total amount.

## Features

- Paradise Nursery landing page.
- Get Started button.
- About Us company information.
- Multiple plant categories.
- Dynamic product listing.
- Add to Cart functionality.
- Remove products from cart.
- Increase and decrease product quantities.
- Automatic cart total calculation.
- Checkout functionality.

## Technologies Used

- React.js
- JavaScript
- Redux Toolkit
- React Redux
- HTML
- CSS

## Project Modules

1. Landing Page
2. About Us
3. Product Listing
4. Shopping Cart
5. Cart Management

## Installation

Run the following commands:

npm install
npm run dev
